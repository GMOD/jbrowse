Hi all, this 1.17.0 release follows up on 1.16.12. It adds a fix for a reflected
XSS in the `&addTracks=` URL parameter (#1670) along with proactive DOMPurify
hardening of innerHTML manipulation. It also removes the node-sass build
dependency by converting the stylesheets from SASS to plain CSS, so installing
and building JBrowse 1 from source works again on current Node and Yarn
versions. We encourage upgrading.

*   [JBrowse-1.17.0.zip](https://github.com/GMOD/jbrowse/releases/download/1.17.0-release/JBrowse-1.17.0.zip) - minified release
*   [JBrowse-1.17.0-dev.zip](https://github.com/GMOD/jbrowse/archive/1.17.0-release.zip) - use this if you modify jbrowse source code or use plugins
*   [JBrowse-1.17.0-desktop-win32-x64.zip](https://github.com/GMOD/jbrowse/releases/download/1.17.0-release/JBrowse-1.17.0-desktop-win32-x64.zip)
*   [JBrowse-1.17.0-desktop-linux-x64.zip](https://github.com/GMOD/jbrowse/releases/download/1.17.0-release/JBrowse-1.17.0-desktop-linux-x64.zip)
*   [JBrowse-1.17.0-desktop-darwin-x64.zip](https://github.com/GMOD/jbrowse/releases/download/1.17.0-release/JBrowse-1.17.0-desktop-darwin-x64.zip)




## Bug fixes

- Fix reflected XSS in the `&addTracks=` URL parameter (<a href="https://github.com/gmod/jbrowse/pull/1670">issue #1670</a>)

- Apply DOMPurify proactively to innerHTML manipulation to harden against XSS
  (<a href="https://github.com/gmod/jbrowse/pull/1660">issue #1660</a>)

- Restore alignments track coloring after the SASS to CSS change (<a href="https://github.com/gmod/jbrowse/pull/1661">issue #1661</a>)

## Build

- Convert SASS to plain CSS and remove the node-sass build requirement, which
  fixes installing and building from source on current Node and Yarn (pull
  #1658)
